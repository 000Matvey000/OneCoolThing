# How 2 Use Markdown for GitHub Profile Home Page

## Why?

GitHub's profile README is a powerful way to showcase your projects, skills, and personality. But how do you make it stand out? This lesson covers the basics of using Markdown to create an engaging GitHub profile home page.

## The Basics

1. Create a repository named as the same as your GitHub username (e.g., `000Matvey000`).
2. Add a `README.md` file to that repository.
3. Write your profile content in Markdown within the `README.md`. This will be displayed on your GitHub profile page.
4. Use Markdown syntax to format your content, add images, links, and even badges.
5. Commit and push your changes to see them live on your profile!
6. Use GitHub's flavor of Markdown to take advantage of features like task lists, tables, and emojis.
7. Consider adding sections like "About Me", "Projects", "Skills", and "Contact" to organize your profile.

See Example [README](./ExampleReadMe.md)

Overall, it is very simple to create a cool GitHub profile home page using Markdown. Just follow the steps above, and you'll have a personalized profile that stands out to visitors!
