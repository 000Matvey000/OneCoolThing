*************************
|Inside of Editor|
*************************

Vim provides 2 modes: 
---------------------

******************
||1. Insert Mode||
******************

Hit the i key to go into Insert mode


******************
||2. Normal Mode||
******************

Hit escape or control + c


******************
||3. Visual Mode||
******************
this mode allows you to visually select text

Shift + v = select lines

CTRL + v = select blocks

-----------------
Keys
-----------------


h = move left
l = move right
j = down
k = up
w = move to beginning of next word
e = move to end of next word
( = move to previous sentence
) = move to next sentence
{ = move to previous paragraph
} = move to next paragraph
/ = search, enter text you would like to search for, keep pressing /"n" to search for the next occurence, use /"?" to
go back 1 occurence. you can use regex in your search as well, eg. s.arch ( . = any character)  

CTRL + F = Move forward a page

CTRL + B = Move backward a page

CTRL + G = shows what file you're in and the line #

SHIFT + G = move to the end of the file

SHIFT + 4 = move to end of the line

0 = move to the beginning of the line

SHIFT + 4 = go to end of line

SHIFT + 8 = go to next occurence of the word you're on

SHIFT + n = to go to previous

CTRL + i = go back 1 jump

CTRL + o = go forward 1 jump

CTRL + W + S = horizontal split 

CTRL + W + V = Vertical Split

-----------------
Number + Key
----------------
Entering a number (eg. 11) then a key (eg. j) will execute the key as many times as the number you specified

----------------
delete stuff
---------------
undo = u

d+w = delete word

d + ) = delete sentence

dd = delete line

x = delete character under cursor

----------------
Copy(y) and paste(p)
----------------

y = copy
yy = copy line

p = paste 
P = paste before cursor


----------------
Mark stuff to get to later
---------------

m [character ] - marks location, lower case is local to current buffer, upper is available to all buffers

to get back to the mark, use a ' (single quote) then use the character

---------------
Jumps
---------------

CTRL + i = go back 1 jump

CTRL + o = go forward 1 jump

Single Quote (') + Period (.) = go to last changed line

----------------
Registers
----------------
registers allow you to copy text into a "register" to use later. 

To open a register enter a " (double quote) followed by a lower or upper case character (up to 52 registers allowed)

Next you can use y or yy to copy the text into the register. Or use visual selection. 

To Paste from a register use " again followed by the character you entered, then use p or P. 

You can also use delete to initiate a register. 

----------------
Change text
----------------

c + w  = change word - deletes word and puts you into insert mode
c + /[text] = change everything up to the text given (will delete everything up to the text and put you in insert mode)

******************
***||Commands||***
******************

-----------------
Get help
-----------------
:help

:help user

vimtutor - launches vim tutor program
-------------------
quit editor - no save
-------------------

:q OR :quit
:qa! - quits all buffers open, ! will force it, unsaved work will be lost

------------------
quit editor - save
------------------
:wq
:wq! - force


------------------
Open file or URL from text
------------------

use :gf


------------------
Buffers
------------------


:e file name - you can use tab completion
:edit file name does the same thing
:e! or edit! will reload the buffer to its original state
:bd will close buffer
:ls will list buffers open, the buffer number can be used in :b # to open the buffer
:bn will go to the next buffer
:bp will go to the previous buffer

:b filename or tab completion will let you cycle through your open buffers and press enter to open 

CTRL + G will show you the file name that you're n

-------------------
Read file into File
-------------------

:r [ file name] will read a file on to the line you're on. 
:-1r [ file name] will read the file on to the previous line
:line#r [ file name] will read the file on to the line specified

:r ![ command] - will read the output of a command to buffer
-------------------
set line numbers on
-------------------
:set number

-------------------
Search for Text
------------------

/ [ your string or regex here]

------------------
split windows
------------------
:split = split window

:split [ file ] = opens file in new window

ctrl + w w = switch between windows

:close = close window

------------------
replace text
------------------

:s/old text/new text - this will replace 1 occurence

:s/old text/new text/g - the g flag will replace all occurences

:s/old text/new text/gc - the c flag will replace all occurences but will ask you to confirm each. 

Go to line number
-----------------
: [ enter your line number]

***************************
***||Config (.vimrc)||*****
***************************

the .vimrc file lives in your home directory

the file should use vimscript syntax. 

" anything after a " is a comment

You can add commands to the file, eg. set number that you normally would type after :

eg: 

set number "comments are in double quote
split ~/.vimrc "test
se ci "set search to be case insensitive 
-------------------
Key Mappings
-------------------

noremap <new key> <old key-combo>

noremap <SPACE> <C-F>


-------------------
Abbreviations
-------------------

abb [ abbreviation] [ abbreviation for]

to disable autofill, you can use CTRL-V

-------------------
Add Commands to your Command area
-------------------
-------------------

comm! [ what you want to call it] ![ command] [ % for current file] 



***************************
***||vi in command line||*****
***************************

vi file +[ line] - start vim on specific line
vi file +1,2d +wq - start vim and delete lines 1-2 and write changes/quit

vi -d file1.txt file2.txt - starts vim in diff mode
	use do (diff obtain) to get the different value
	use dp (diff put) to put the different value

you can use diffsplit in the editor to launch diff as well
or use vert diffsplit to do a vertical split


***************************
***||zip files||*****
***************************

vi file.zip - will open the zip file contents
	Make sure you have zip/unzip installed, macOS should have it
